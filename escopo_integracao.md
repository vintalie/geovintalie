## ESCOPO DO PROJETO: integracao-property-linker

**Objetivo:** Integrar completamente o design e componentes do property-linker como design principal da aplicação geovintalie. Substituir design antigo (Bootstrap) pelo design do property-linker (Tailwind CSS, shadcn/ui). Garantir que páginas como login, etc. usem o novo design.

**Entregáveis:**
1. [DESENVOLVIMENTO] Migração do frontend para usar design system do property-linker (Tailwind CSS, componentes shadcn/ui)
2. [DESENVOLVIMENTO] Integração completa das páginas principais com novo design
3. [DESENVOLVIMENTO] Correção da rota /login e outras páginas para usar novo design
4. [DESENVOLVIMENTO] Garantir compatibilidade com API e rotas existentes

**Critérios de aceitação:**
- Página /login usa design do property-linker (não design antigo)
- Aplicação usa componentes e estilos do property-linker
- Design consistente em toda aplicação
- Funcionalidades existentes mantidas

**Delegação:** Múltiplos agentes em diferentes perfis trabalhando em paralelo
**Prazo relativo:** Imediato
**Responsável:** Orquestrador
